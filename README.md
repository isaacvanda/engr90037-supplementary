# ENGR90037 Final Report: Supplementary Material

This repository holds the supplementary material for the ENGR90037 final report. The archive `engr90037-supplementary.zip` is attached to the [v1 release](../../releases/tag/v1). It is password protected, and the password is given in the report. The archive opens in Windows Explorer or any standard unzip tool. `MANIFEST.txt` lists every file in the archive with its size and SHA-256, the source commit of each code folder, and the files that were redacted.
